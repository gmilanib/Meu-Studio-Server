# MeuStudio Clientes

Interface React para cadastro, listagem, edicao e exclusao de clientes.

## Como executar

1. Instale Node.js 20 ou superior.
2. Inicie o backend Spring Boot na porta `8080`.
3. Instale as dependencias:

```bash
npm install
```

4. Rode o frontend:

```bash
npm run dev
```

O Vite abre a interface em `http://localhost:5173` e encaminha `/clientes` para `http://localhost:8080`.
